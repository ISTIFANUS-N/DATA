Official provider logos
=======================

Put a logo file here, named in lowercase after the provider code, and the app uses it
automatically (no code change). SVG or PNG; square or near-square works best.

Networks:   mtn  glo  airtel  9mobile
Electricity: ikedc  ekedc  aedc  phedc  kedco  ibedc  eedc  jedc  kaedco  yedc  bedc  aba
Cable TV:   dstv  gotv  startimes

Examples: mtn.svg, ikedc.png, dstv.svg

If a file is missing, a brand-coloured badge is shown for that provider.
Only use logos you are allowed to use (for example from the provider's brand/press page).
